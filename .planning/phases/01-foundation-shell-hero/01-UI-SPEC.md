## Spacing Scale

Standard 8-point scale (multiples of 4). Declared values mapped to Tailwind arbitrary values used across the Mutual group LPs.

| Token | Value | Tailwind | Usage |
|-------|-------|----------|-------|
| xs | 4px | `p-1`, `gap-1` | Icon dot indicators, inline separator gaps |
| sm | 8px | `p-2`, `gap-2` | Badge internal padding, compact component gaps |
| md | 16px | `p-4`, `gap-4` | Default element spacing, container horizontal padding (mobile) |
| lg | 24px | `p-6`, `gap-6` | Card internal padding, tablet gaps |
| xl | 32px | `p-8`, `gap-8` | Component group separation |
| 2xl | 48px | `py-12` | Dense section vertical padding (mobile) |
| 3xl | 64px | `py-16` | Hero top padding (mobile); large section breaks |
| 4xl | 80px | `py-20` | Standard section vertical padding (mobile) |
| 5xl | 96px | `py-24` | Standard section padding (tablet) |
| 6xl | 128px | `py-32` | Standard section padding (desktop) |

**Section vertical padding pattern:**
- Hero: `pt-16 pb-0 sm:pt-20 md:pt-24` (no bottom padding — bleeds into next section)
- Standard sections (Fase 2+): `py-20 sm:py-24 lg:py-32`

**Container:**
- Max width: `max-w-[1250px]` — centered with `mx-auto`
- Horizontal padding: `px-4 sm:px-6 lg:px-8`

**Grid gaps:**
- Cards: `gap-4` (mobile) → `gap-6` (tablet) → `gap-10` (desktop)

**Exceptions (justified deviations from the standard {4,8,16,24,32,48,64} set — all multiples of 4):**
- **Section padding scale extended to 80/96/112/128/144/176px** (`py-20`/`py-24`/`pb-28`/`py-32`/`pt-36`/`pt-44`): herdado do padrão do grupo em `CONVENTIONS.md §Spacing`. Justificado pelas alturas de seção de LP editorial e pela necessidade de espaço extra no topo do hero (clear da navbar + authority bar). Decisão de manter consistência com `lp-otc-mutual`/`lp-mutual-capital`.
- Desktop card gap `gap-10` (40px): padrão de grid do grupo.
- Authority-bar: `py-2 px-4` (ultra-compact faixa — ~8px vertical)
- Floating CTA: fixed `bottom-7 right-7` (28px from edges)
- Touch targets on mobile: minimum 44px height on all interactive elements (button + anchor tags)
- Navbar pill inner padding: `px-4 py-2` collapsed; `px-6 py-4` expanded

Source: CONVENTIONS.md §Spacing.

## Typography

**Primary font stack:** `'Montserrat', sans-serif` — applied globally via `* { font-family: 'Montserrat', sans-serif; }` in styles.css.

**Note on Inter:** Some reference LPs use Inter as a body override. For Mutual Advisory, Montserrat is used exclusively — no Inter. Source: CONTEXT.md D-07 (editorial "private bank" aesthetic).

**Declared weights: 400 (regular body), 500 (mid-scale: nav links, h1 default, eyebrow), 600 (semibold: headings, CTAs, h1 `<em>`), 700 (footer headings, authority-val).**

> **Decisão de design (aprovada pelo usuário, 2026-06-16):** Esta escala tipográfica (Montserrat 400/500/600/700, ~8 papéis responsivos de 11px a 64px) é **herdada do design system do grupo** (`CONVENTIONS.md §Typography`) e mantida deliberadamente para preservar a consistência visual com as LPs irmãs (`lp-otc-mutual`, `lp-mutual-capital`). A regra genérica do verificador de UI ("máx 4 tamanhos / 2 pesos") aplica-se a apps de produto; para uma landing page editorial de 19 seções com design system de grupo consolidado, a escala completa é intencional e não constitui proliferação ad-hoc. **Este é o contrato canônico de tipografia.**

## Component Specifications

### 1. Authority Bar (SHL-01)

**Structure:** Fixed-position faixa at the very top (above navbar), z-40. Disappears on scroll (hides when navbar transitions to pill at ~80px).

**Copy (word-for-word from v4.html lines 532–540):**
```
Mutual Advisory · Membro do Grupo Mutual Capital · Inteligência Patrimonial · Tecnologia Financeira · Presença Global · mutualcapital.com.br →
```

**Visual spec:**
- Background: `bg-[#0D1525]` (slightly lighter than `--dark-bg`, creating subtle separation)
- Text: `text-[#8898C0]` (`--text-muted`) at 13px, weight 400
- Separators `·`: `text-[#1B2A46]` (`--border`) slightly muted
- Link `mutualcapital.com.br →`: `text-[#FCB71B]` gold, hover underline, `href="https://mutualcapital.com.br"` target blank
- Padding: `py-2 px-4` (8px vertical, 16px horizontal)
- Border bottom: `border-b border-[#1B2A46]`
- Height: ~36px rendered
- Overflow: `overflow-hidden`, single line, `text-center`
- Z-index: `z-40` (below navbar z-50)

**Behavior:**
- Visible on page load (opacity 1)
- Disappears via GSAP when scroll passes 80px: `gsap.to('#authority-bar', { opacity: 0, y: -36, duration: 0.38, ease: 'power2.inOut' })` tied to same ScrollTrigger as navbar pill transition
- DOM stays in place (not removed); `pointer-events: none` after hide

**Accessibility:**
- `role="banner"` or wrapped in `<div aria-label="Authority bar">`
- Link has descriptive text; no ARIA needed beyond `target="_blank"` + `rel="noopener noreferrer"`

ScrollTrigger.create({

## Motion Contract (MOT-03 + GSAP)

**Global constraint:** NO `scroll-behavior: smooth` in CSS. All smooth scroll delegated to Lenis. See ARCHITECTURE.md §Anti-Patterns.

**Initialization order (DOMContentLoaded):**
1. `gsap.registerPlugin(ScrollTrigger)`

6. Init hero entrance timeline
7. Init floating CTA trigger
