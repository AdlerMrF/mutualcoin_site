## Directory Purposes

**Root (`lp-mutual-advisory/`):**
- Purpose: Project root with entry files and build config
- Key files: `index.html` (rendered page), `package.json` (deps), `vite.config.js` (dev server)

**`src/assets/css/`:**
- Purpose: Tailwind CSS initialization + custom animations + CSS variables
- Contains: `styles.css` (single file, Vite import) with `@tailwind` directives, `@keyframes`, `:root` vars, responsive utilities
- Key features: Magic card glow via radial-gradient + CSS vars, shine-text animation, fade-in on scroll, glass-morphism effects

**`src/assets/img/`:**
- Purpose: Image assets (logos, screenshots, backgrounds, icons)
- Contains: SVG logos, WebP optimized photos, PNG fallbacks
- Optimization: Compress to <100KB per image; use WebP with PNG fallback in HTML `<picture>` tags
- Example files: `logo_branca.svg` (navbar, white), `hero-dashboard.png` (hero section), `feature-cambio.webp` (bento card background)

**`src/js/animations/`:**
- Purpose: Modular animation setup (optional, for scaling)
- Contains: One module per animation type (hero reveals, counters, navbar, GSAP config)
- Used by: `index.js` imports these to initialize animations on page load
- Pattern: Each module exports a setup function: `export function initHeroAnimations() { ... }`

**`dist/`:**
- Purpose: Vite build output (minified, bundled, optimized)
- Generated by: `npm run build`
- Deployed to: Web server (static hosting, CDN)
- Gitignored: Never commit dist/

**`.planning/codebase/`:**
- Purpose: GSD analysis documents (ARCHITECTURE.md, STRUCTURE.md, etc.)
- Generated by: `/gsd-map-codebase` orchestrator
- Gitignored: Not deployed, reference only

## Where to Add New Code

### New Feature (e.g., Contact Form)

**Primary code:**
1. Add form HTML to `index.html` (new `<section id="contact">` with form fields)
2. Add form styles to `src/assets/css/styles.css` (input focus states, validation feedback)
3. Add form handler to `index.js` or `src/js/animations/contact.js`:
   ```javascript
   // Example: form validation + API submit
   document.getElementById('contact-form').addEventListener('submit', async (e) => {
     e.preventDefault();
     // Validate, POST to backend
   });
   ```

**Tests:**
- Manual E2E: Open `http://localhost:5173`, interact with form
- Playwright test (if added): `tests/contact-form.spec.ts`

**Styling pattern:**
- Use Tailwind utility classes for layout: `flex`, `gap-4`, `rounded-lg`, etc.
- Use CSS custom properties for colors: `var(--color-primary)`, `var(--border)`
- Reserve `styles.css` for keyframes, responsive tweaks, and edge cases

### New Component/Module (e.g., Video Embed, Testimonials Carousel)

**Implementation:**
1. Create section HTML in `index.html`:
   ```html
   <section id="testimonials" class="py-20 bg-[#0C1220]">
     <div class="max-w-[1250px] mx-auto px-4">
       <!-- testimonial cards -->
     </div>
   </section>
   ```

2. Create styles in `src/assets/css/styles.css`:
   ```css
   .testimonial-card {
     /* Tailwind classes override here if needed */
     transition: transform 0.3s ease;
   }
   ```

3. If interactive (carousel, lightbox), add to `index.js` or `src/js/animations/testimonials.js`:
   ```javascript
   export function initTestimonials() {
     const carousel = document.getElementById('testimonials-carousel');
     // Setup carousel logic, event listeners, animation triggers
   }
   ```

### Utilities (e.g., Shared Helpers, Animation Configs)

**Location:** `src/js/utils/` or `src/js/animations/` (depending on scope)

**Pattern:**
```javascript
// src/js/utils/easing.js
export const easeOutExpo = (t) => t === 1 ? 1 : 1 - Math.pow(2, -10 * t);

// src/js/animations/gsap-config.js
import gsap from 'https://cdnjs.cloudflare.com/ajax/libs/gsap/3.12.5/gsap.min.js';
import ScrollTrigger from 'https://cdnjs.cloudflare.com/ajax/libs/gsap/3.12.5/ScrollTrigger.min.js';

gsap.registerPlugin(ScrollTrigger);
export const gsapDefaults = { ease: 'power2.out', duration: 0.7 };
```

**Used by:** Import in `index.js` or other modules:
```javascript
import { easeOutExpo } from './utils/easing.js';
import { gsapDefaults } from './animations/gsap-config.js';
```

## Build & Development Workflow

**Development:**
```bash
npm install                    # Install dependencies (Lenis, GSAP from CDN)
npm run dev                    # Start Vite dev server (http://localhost:5173)
```
- Hot reload on file save
- Vite processes `@tailwind`, `@import` in styles.css
- Source maps available for debugging

**Build:**
```bash
npm run build                  # Vite minifies HTML, JS, CSS; optimizes images
npm run preview               # (Optional) test production build locally
```
- Output in `dist/`
- Ready for deployment

**Deployment (Example: GitHub Pages):**
```bash
npm run build
git add dist/
git commit -m "Build"
git push origin main
# GitHub Pages auto-deploys from dist/ (if configured)
```

## Import/Export Pattern

**Module approach (if modularized):**
```javascript
// src/js/animations/hero.js
export function initHeroAnimations() {
  gsap.to('.hero-badge', { ... });
}

// index.js (entry point)
import { initHeroAnimations } from './js/animations/hero.js';
import Lenis from 'https://cdn.jsdelivr.net/npm/lenis@1.3.21/+esm';

const lenis = new Lenis({ ... });

document.addEventListener('DOMContentLoaded', () => {
  initHeroAnimations();
  // ... other setup
});
```

**CDN approach (current refs: lp-otc-mutual):**
```html
<!-- index.html -->
<script src="https://cdnjs.cloudflare.com/ajax/libs/gsap/3.12.5/gsap.min.js"></script>
<script type="module" src="./index.js"></script>

<!-- index.js uses global GSAP -->
gsap.to('.selector', { ... });
```

Choose **module approach** for better bundling + tree-shaking. Choose **CDN approach** for simpler setup (fewer build steps).

## CSS Architecture

**Layer order in `styles.css`:**
1. `@tailwind base;` — Reset + semantic HTML styling
2. `@tailwind components;` — Reusable component classes (not heavily used here)
3. Custom CSS vars (`:root { --color-primary: ... }`)
4. Custom animations (`@keyframes fadeIn`, `@keyframes shine-gradient`)
5. Custom utilities (`.magic-card`, `.glass-card`, `.fade-in`)
6. `@tailwind utilities;` — Tailwind utilities (override custom if needed)
7. Media queries (`@media (max-width: 768px)`)

**Scoped styling (if needed):**
Use CSS custom properties instead of utility classes for theme colors:
```css
:root {
  --color-primary: #FCB71B;
  --color-bg: #0C1220;
}

section[data-theme="light"] {
  --color-primary: #1235F2;
  --color-bg: #FFFFFF;
}

.button { background: var(--color-primary); }
```
